# Itzel Salazar | Portfolio

Personal portfolio site: https://salazaritzel.github.io/portfolio/

A single-page static site built with HTML, CSS, and vanilla JavaScript.
It contains, the following sections: projects, skills, education, and contact, with a
responsive layout and a mobile menu.

## Built with

- HTML, CSS, JavaScript
- Playwright for browser tests
- GitHub Pages for hosting

Built this site with GitHub Copilot, starting from a written ADR that defined the scope. Every change was made through small, detailed prompts. I supplied all the content, reviewed each change, and made my own design decisions over Copilot's generated ones. Playwright tests were generated and used to check the generated code.
